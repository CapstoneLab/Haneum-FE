HAN2 안전 키보드 사용자 설명서
버전 0.1.4
최종 수정일: 2026-08-11

==================================================
1. HAN2 소개
==================================================

HAN2는 Android의 검색창, 채팅창, 메모, 브라우저 등 일반적인 텍스트 입력창에서 사용할 수 있는 안전 키보드입니다.
사용자가 입력하는 동안 개인정보, 인증정보, 금융사기 유도 문구, 위험 표현 등을 확인하고 키보드 상단에 안전 상태를 보여줍니다.

현재 버전은 백엔드 연결 전 단계입니다. 위험 판단은 기기 안에 구현된 기본 규칙으로 처리됩니다.
향후 백엔드 분석 API가 준비되면 현재 키보드 입력 파이프라인에 추가로 연결할 예정입니다.


==================================================
2. 현재 구현된 주요 기능
==================================================

- Android 시스템 키보드(IME) 등록
- 모든 호환 검색창과 텍스트 입력창에서 자동 표시
- 물리 키보드가 연결된 에뮬레이터에서도 화면 키보드 표시
- 기본 한글 두벌식 조합 입력
- 한글/영문 전환
- 숫자 키패드 전환
- 삭제, 공백, 입력 및 검색 실행
- 입력창 종류에 따른 실행 버튼 자동 변경
  · 검색
  · 진행
  · 전송
  · 다음
  · 이전
  · 완료
  · 입력
- 키보드 상단 실시간 상태 표시
  · 안전: 위험 요소가 발견되지 않음
  · 주의: 개인정보 또는 금융사기 가능성 확인 필요
  · 위험: 민감정보 또는 심각한 위험 표현 감지
- 비밀번호 입력 시 분석과 기록 자동 중지
- 위험 상태에서 실행 버튼을 누르면 동작 보류
- 수정하기 또는 그래도 진행 선택 제공
- 경고 후 진행한 내역을 감지 보고서에 기록
- 설정 앱을 닫아도 별도 키보드 프로세스에서 감지 유지
- 앱 설정을 실제 네이티브 키보드에 반영
- 감지 보고서 조회 및 삭제


==================================================
3. 설치 전 준비
==================================================

개발 및 빌드에 필요한 프로그램:

- Node.js
- JDK 21
- Android Studio 또는 Android SDK
- Android 기기 또는 Android 에뮬레이터

의존성이 설치되지 않은 경우 프로젝트 폴더에서 다음 명령을 실행합니다.

npm.cmd install


==================================================
4. Android 앱 빌드 방법
==================================================

4-1. 웹 화면 빌드 및 Android 동기화

npm.cmd run mobile:sync

4-2. Android 디버그 APK 빌드

cd android
gradlew.bat assembleDebug

생성되는 APK 위치:

android\app\build\outputs\apk\debug\app-debug.apk

4-3. Android Studio에서 실행

프로젝트 루트에서 다음 명령을 실행합니다.

npm.cmd run android:open

Android Studio가 열리면 연결된 기기 또는 에뮬레이터를 선택하고 Run 버튼을 누릅니다.


==================================================
5. HAN2 키보드 최초 설정
==================================================

Android 보안 정책상 앱이 사용자의 동의 없이 기본 키보드를 강제로 변경할 수 없습니다.
최초 한 번은 아래 과정을 직접 진행해야 합니다.

1. HAN2 앱을 실행합니다.
2. 화면 상단의 '키보드 추가'를 누릅니다.
3. Android 키보드 목록에서 'HAN2 안전 키보드'를 활성화합니다.
4. HAN2 앱으로 돌아옵니다.
5. '선택하기'를 누릅니다.
6. 키보드 선택창에서 'HAN2 안전 키보드'를 선택합니다.
7. 상단 상태가 '기본 키보드'로 변경됐는지 확인합니다.

이 과정을 완료하면 Google, YouTube, 브라우저, 메모, 메시지 등 다른 앱에서도 HAN2가 표시됩니다.


==================================================
6. 키보드 사용 방법
==================================================

1. 검색창이나 입력 가능한 텍스트 영역을 누릅니다.
2. 화면 아래에서 HAN2 키보드가 자동으로 열립니다.
3. 키보드 상단에서 현재 안전 상태를 확인합니다.
4. 내용을 입력한 다음 오른쪽 아래 실행 버튼을 누릅니다.

입력창의 용도에 따라 오른쪽 아래 버튼 이름이 자동으로 달라집니다.

- 검색창: 검색
- 웹 주소 또는 이동 입력: 진행
- 채팅 및 메시지: 전송
- 여러 단계 입력: 다음 또는 이전
- 마지막 입력 단계: 완료
- 일반 입력: 입력

숫자 키패드가 필요한 경우 '123'을 누릅니다.
한글 키보드로 돌아가려면 '한글'을 누릅니다.


==================================================
7. 안전 상태 설명
==================================================

7-1. 안전

초록색으로 표시됩니다.
현재 확인된 범위에서 위험 요소가 발견되지 않은 상태입니다.

7-2. 주의

노란색으로 표시됩니다.
다음과 같은 내용이 포함됐을 가능성이 있습니다.

- 전화번호와 유사한 번호
- 계좌 또는 송금 관련 문구
- 상품권 및 대출 유도 표현
- HTTP 또는 단축 링크

주의 상태는 실행을 강제로 막지 않으며 사용자가 내용을 다시 확인하도록 안내합니다.

7-3. 위험

빨간색으로 표시됩니다.
다음과 같은 내용이 감지될 수 있습니다.

- 주민등록번호 형태
- 비밀번호, OTP 또는 인증번호와 숫자의 조합
- 위협, 협박 또는 자해 관련 고위험 표현

위험 상태에서 검색, 진행, 전송, 완료 또는 입력 버튼을 누르면 원래 동작을 즉시 실행하지 않고 확인 절차를 표시합니다.


==================================================
8. 위험 입력 확인 절차
==================================================

위험 상태에서 실행 버튼을 누르면 다음 메시지가 키보드 안에 표시됩니다.

'위험으로 판단되어 검색/진행/전송을 중지했습니다.'
'정말로 이 내용을 진행하시겠습니까?'

선택 가능한 작업:

- 수정하기
  실행을 취소하고 입력 내용을 수정합니다.

- 그래도 진행
  원래 검색, 진행, 전송 또는 완료 동작을 수행합니다.
  이 선택은 감지 보고서에 '경고 후 진행'으로 기록됩니다.

중요:
HAN2는 키보드 오른쪽 아래의 Android 입력 액션을 보류할 수 있습니다.
외부 앱 화면에 별도로 만들어진 전송 버튼을 직접 누르는 동작은 Android 보안 구조상 키보드가 강제로 차단할 수 없습니다.
이 경우에도 키보드 상단의 위험 경고는 계속 표시됩니다.


==================================================
9. 감지 보고서 사용 방법
==================================================

1. HAN2 설정 앱을 실행합니다.
2. 화면 맨 아래로 이동합니다.
3. '감지 보고서'의 '보기'를 누릅니다.

보고서에서 확인할 수 있는 내용:

- 전체 감지 건수
- 위험 건수
- 주의 건수
- 감지 유형
- 감지 이유
- 숫자를 가린 입력 미리보기
- 감지 시간
- 사용자가 경고 후 진행했는지 여부

개인정보 보호 정책:

- 입력 원문 전체를 저장하지 않습니다.
- 보고서의 모든 숫자는 '•' 기호로 가립니다.
- 최대 30건만 기기에 저장합니다.
- 동일한 감지는 30초 동안 중복 기록하지 않습니다.
- 비밀번호 입력은 보고서에 기록하지 않습니다.
- '기록 비우기'를 누르면 저장된 보고서를 삭제할 수 있습니다.


==================================================
10. 앱 설정과 실제 키보드 동기화
==================================================

HAN2 앱에서 변경한 다음 설정은 실제 Android 키보드에 저장됩니다.

- 안전 입력 보호 ON/OFF
- 키 입력 진동
- 키 입력 소리
- 숫자 행 표시
- 시스템/라이트/다크 테마

설정을 변경한 후 다른 앱에서 키보드를 다시 열면 최신 설정이 적용됩니다.
설정값은 앱을 닫아도 기기에 유지됩니다.


==================================================
11. 백그라운드 동작
==================================================

키보드 감지는 HAN2 설정 화면이 아니라 Android 키보드 서비스 안에서 실행됩니다.
따라서 홈으로 이동하거나 최근 앱 화면에서 HAN2 설정 앱을 닫아도 키보드를 열면 감지가 계속 동작합니다.

키보드를 사용하지 않는 동안에는 입력 내용을 감지하지 않습니다.
이는 개인정보 노출과 배터리 사용을 줄이기 위한 설계입니다.

Android 설정에서 HAN2 앱을 '강제 종료'하면 운영체제가 모든 HAN2 서비스를 차단합니다.
강제 종료 후에는 HAN2 앱을 다시 실행해야 키보드 서비스가 정상 복구됩니다.


==================================================
12. 비밀번호 및 민감 입력 보호
==================================================

Android가 입력창을 비밀번호, PIN 또는 숨김 입력으로 알려주는 경우 HAN2는 다음 기능을 중지합니다.

- 문장 분석
- 추천
- 입력 기록
- 감지 보고서 작성

키보드 상단에는 다음 상태가 표시됩니다.

'보호 · 민감정보 입력 중'
'분석과 저장을 중지했어요'


==================================================
13. 문제 해결
==================================================

13-1. 입력창을 눌러도 키보드가 나타나지 않는 경우

1. HAN2 앱 상단 상태가 '기본 키보드'인지 확인합니다.
2. '선택하기'를 눌러 HAN2 안전 키보드를 다시 선택합니다.
3. Android 설정 > 시스템 > 키보드 > 화면 키보드에서 HAN2가 활성화됐는지 확인합니다.
4. 앱을 강제 종료했다면 HAN2 앱을 다시 실행합니다.
5. 대상 입력창이 읽기 전용 또는 입력 금지 상태인지 확인합니다.

13-2. 에뮬레이터에서 키보드가 나타나지 않는 경우

에뮬레이터가 PC 키보드를 물리 키보드로 인식할 수 있습니다.
현재 HAN2는 물리 키보드가 연결돼 있어도 화면 키보드를 표시하도록 구현되어 있습니다.
그래도 표시되지 않으면 에뮬레이터 설정에서 'Show virtual keyboard'를 활성화합니다.

개발용 에뮬레이터에서는 프로젝트 루트의 다음 파일을 실행하는 것을 권장합니다.

run-android-han2.cmd

이 실행 파일은 에뮬레이터 부팅을 기다린 뒤 최신 APK 설치, HAN2 키보드 활성화,
기본 입력기 선택, 물리 키보드 연결 중 화면 키보드 표시를 자동으로 복구합니다.

13-3. 앱 안의 키보드 모양을 눌러도 입력되지 않는 경우

HAN2 설정 화면의 '나의 키보드' 영역은 디자인 미리보기입니다.
실제 입력은 흰색 테스트 입력창을 눌러 나타나는 Android HAN2 키보드에서 진행합니다.

13-4. 설정이 실제 키보드에 반영되지 않는 경우

키보드를 닫았다가 입력창을 다시 눌러 새로 엽니다.
계속 반영되지 않으면 HAN2 앱을 실행해 설정을 한 번 변경한 뒤 다시 확인합니다.


==================================================
14. 현재 버전의 제한사항
==================================================

- 백엔드 위험 분석 API는 아직 연결되지 않았습니다.
- 현재 위험 판단은 기기 내 기본 문자열 및 번호 규칙을 사용합니다.
- 기본 한글 조합은 지원하지만 쌍자음, 복합모음, 겹받침 처리는 추가 보완이 필요합니다.
- 문장 추천 기능은 설정 UI가 준비되어 있으나 실제 추천 엔진은 아직 연결되지 않았습니다.
- 앱 화면 자체의 전송 버튼은 키보드에서 강제로 차단할 수 없습니다.
- 규칙 기반 감지에는 오탐과 미탐이 있을 수 있습니다.
- 현재 보고서는 로컬 기기 저장소에만 보관됩니다.


==================================================
15. 백엔드 연결 예정 구조
==================================================

백엔드가 준비되면 다음 흐름으로 연결할 예정입니다.

1. 키보드에서 입력 문장 확인
2. 비밀번호 및 민감 필드 제외
3. 로컬 규칙으로 1차 검사
4. 허용된 범위의 문장을 백엔드 분석 API로 전달
5. 위험 등급, 유형, 이유 및 수정 제안 수신
6. 키보드 상태 영역에 결과 표시
7. 위험 실행 버튼 보류 및 사용자 확인
8. 필요한 최소 정보만 보고서에 기록

백엔드 연결 시에는 전송 동의, 암호화, 보관 기간, 원문 폐기 정책을 별도로 확정해야 합니다.

18. 현재 상태 요약
==================================================

HAN2 0.1.4는 Android 시스템에서 선택 가능한 실제 안전 키보드로 동작합니다.
호환되는 텍스트 입력창을 누르면 자동으로 표시되고, 앱을 닫아도 별도 키보드 프로세스에서 입력 중 안전 상태를 확인합니다.
위험 상태에서는 키보드의 검색, 진행, 전송, 완료 및 입력 동작을 보류하고 사용자의 최종 확인을 받습니다.
감지 내용과 판단 이유, 경고 후 진행 여부는 개인정보를 가린 로컬 보고서로 확인할 수 있습니다.

현재 단계의 핵심 보완 과제는 완전한 한글 조합, 실제 문장 추천, 백엔드 위험 분석 API 연결 및 보안 검증입니다.
